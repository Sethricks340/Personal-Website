Active Cooperative Terrain-Aided Navigation Using Inverted USBL; Base Station GUI

(May 2025 - July 2025)

I was apart of this group at my internship at the FRoSt Lab. The goal of the project was to have a multi-agent fleet navigating autonomously together, communicating over modem and estimating position based off of differences in the terrain. My specific assignment was to create a GUI for the base station, because when I arrived everything was operating from terminal. Now with the GUI we can see the status of the vehicles while they are in the mission, including location data and system status. This is done by communicating through a base station modem near the shore and connected to the base station computer. Click on this link to see the code I wrote for this GUI: GUI GitHub I also wrote extensive documentation on the GUI, so that it could still be used and learned after I left.
